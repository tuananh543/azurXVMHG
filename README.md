# Trang giới thiệu Đoàn Nghi Lễ Quân Đội

- **Sửa nội dung** (tên, giới thiệu, số liệu, thành viên, liên kết): mở `config.js`.
- **Đổi ảnh**: thay file trong thư mục `images/` giữ nguyên tên
  (`cover.jpg` = ảnh bìa, `avatar.jpg` = ảnh đại diện, `logo.png` = icon hợp tác thứ 1, `partner.svg` = icon hợp tác thứ 2),
  hoặc đổi đường dẫn trong `config.js`.
- **Sửa giao diện**: `style.css`. **Xem trang**: mở `index.html`
  (khuyên dùng tiện ích Live Server trong VS Code để tự tải lại khi lưu).
